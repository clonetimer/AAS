# AAS Windows 离线包部署说明

适用环境：Windows 10/11 x64。部署过程不访问 PyPI。

## 安装

1. 解压整个 ZIP，不要单独移动包内文件。
2. 双击 `一键部署.cmd`。
3. 默认安装到当前用户的 `%LOCALAPPDATA%\AAS`。也可在命令行指定其他路径：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Deploy-AAS.ps1 -TargetDir 'E:\AAS'
   ```

4. 使用示例遥测建库时，目标盘需要约 35 GB 可用空间。安装器会在创建目标目录前检查空间，并在安装前逐项核验 SHA-256。
5. 安装完成后，双击安装目录中的 `Start-AAS.cmd`，浏览器打开 `http://127.0.0.1:8765`。
6. 首次访问时设置本机管理员账号和密码。

## 启动、停止和卸载

- `Start-AAS.cmd`：启动服务并打开浏览器。
- `Stop-AAS.cmd`：请求服务正常停止，不删除数据库或模型。
- `Uninstall-AAS.cmd`：输入 `REMOVE` 确认卸载。默认把 `datasets`、`models` 和 `configs` 移到同级备份目录。
- 只有明确使用 `Uninstall-AAS.ps1 -DeleteUserData` 并再次输入 `DELETE DATA`，才会删除用户数据。

## 数据和模型

离线包包含示例遥测 CSV.GZ 与标签，不包含预置实验模型。训练和测试 CSV 保存于独立用户 CSV 工作区，不写入历史遥测库。不要手工删除正在使用的 SQLite 文件。

若从旧数据库迁移，请先停止旧服务，再使用新的目标目录和 `-DatabaseSource`。安装器会复制来源数据库，在副本上迁移；不会修改原始数据库文件。

## 故障排查

部署日志位于系统临时目录，文件名以 `AAS_Deploy_` 开头。服务日志位于安装目录 `logs\service.stdout.log` 和 `logs\service.stderr.log`。安装失败时，若目标目录由本次安装创建，安装器会清理该目录；原数据库来源不会被删除。

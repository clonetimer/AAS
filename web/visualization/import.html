外部遥测数据导入

支持 CSV、CSV.GZ 和 SQLite（DB/SQLite）本地文件；SQLite 先选择数据表。时间列可在检查后手动选择，多列数值参量一次导入并分别登记为逻辑参量。先检查和预检，再确认写入当前活动历史库；上传的源文件只读使用。

CSV 文件格式确认

系统先自动识别编码与分隔符；如识别不正确，可修改后点击“检查文件与字段”。预检和导入只使用已确认的格式。

来源身份与标签证据（可选）
数据来源与运行身份

运行 token 用于避免不同运行混同；有 targets 单成员 JSON 时可自动带出 token / split / group。运行元数据不会作为模型特征。

数据质量检查（只读）

先检查文件格式，再查看缺失、无效值与时间异常。显示最多 20 项问题；正式导入仍执行严格完整校验。

尚未检查文件。

列角色与参量选择

将有效数值列勾选为参量；文本说明列建议保持忽略。忽略已有 0/1 标签不等于数据全部正常。

参量属性绑定

优先使用已知的 56 项参量目录自动匹配；未匹配或缺少可信单位的列须手动修改，亦可上传完整映射 CSV 覆盖。

本机列映射预设

仅保存列角色和参量属性，不保存遥测数据；仅可应用于列集合相同的文件。

列属性绑定核对

选择文件后会自动填充已知参量；每行可检查并修改分系统、部件、参量和单位，无法可靠匹配的字段不得空缺。

标签范围与真实性

运行级 label=1 不代表每个部件或参量发生故障；部件/参量事件请使用独立的真值复核流程。

数据用途必须选择；系统不会从缺失的标签推断正常或故障。

导入前质量与一致性预检

预检将报告缺测、时间间隔、间断、标签数量、运行身份冲突和文件摘要；预检不写入数据库。

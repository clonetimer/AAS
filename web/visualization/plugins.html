插件配置与文件导入

先选择插件类型和实现语言，再加载示例或导入本地文件。右侧可直接编辑全部文件内容。

C/C++ 插件使用独立 Native Plugin Host 子进程运行，DLL/SO 不直接加载到 AAS Python 主服务。宿主以 python -I -S 启动，仅使用标准库 ctypes，并通过认证的本机 IPC 传递数据；原生崩溃会终止宿主而不是主服务。AAS 本机编译同样清理 Python/venv/Conda 环境。注意：这仍不是恶意代码权限沙箱，只处理可信源码。

插件文件编辑区

可完整编辑 YAML 描述和 Python / C / C++ 源码；文本区域支持拖动调整高度，保存前可解析校验。

本机隔离编译 调用系统 GCC/Clang/MSVC 子进程；不使用 Python 包作为 C/C++ 编译依赖，不接受任意编译参数。编译/ABI 校验完成后，实际运行仍由独立 Native Plugin Host 承载。也可以跳过编译，直接“导入已编译库”。
查看开发说明
  1. Python 插件：使用 class_path + Python 类契约。检测算法按 decision_mode 实现对应能力，阈值策略属于检测算法内部参数；故障类型插件会直接出现在“模拟故障数据库”的故障类型列表。
  2. C/C++ 插件：检测算法和评估指标统一使用稳定 C ABI（aas_native_v1），C++ 导出函数使用 extern "C"。可由 AAS 调用系统 GCC/Clang/MSVC 编译源码，也可直接导入已编译 DLL/SO；安装前会进行 ABI 与导出函数校验。
  3. 运行与安装：原生插件由独立 Native Plugin Host 承载，主进程通过认证本机 IPC 交换数据，插件崩溃不会直接带崩主服务；但它仍具有当前系统账号权限，不属于恶意代码安全沙箱。安装失败自动回滚，自定义插件可卸载，内置插件受系统保护。

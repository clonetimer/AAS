# 实验重复性与算法输入可比性

本功能用于核验**实际投入算法的数据是否一致**，不替检测器设置阈值、报警条件或后处理，也不强制不同算法采用同一种预处理。

## 从历史任务中比较

“结果报表”左侧选择“对比两个实验的数据输入条件”，选取两项**已经保存历史归档**的训练或评估任务并点击“检查可比性”。也可以运行：

```bash
python scripts/compare_experiments.py <实验编号A> <实验编号B>
```

HTTP：`GET /api/compare-experiments?left=<实验编号A>&right=<实验编号B>`（需要登录）。不接受任意路径，服务端只读取受管 `outputs/experiment_<ID>/reports/summary.json`，先核验结果、执行配置及存在时的完整输入快照的哈希，再进行比较。接口不修改模型或历史文件。

| 结果类型 | 解释 | 适用比较 |
|---|---|---|
| `identical_model_inputs` | 有序的训练集、测试集、标签和实际模型输入向量全部一致 | **控制输入条件的算法比较**（但算法内部随机性、模型超参、平台环境仍可能不同） |
| `same_raw_inputs_different_preprocessing` | 采样选择和归一化前值一致，归一化后值不同 | **整套算法/预处理方案比较**；不能认定是在相同模型输入上比较算法 |
| `same_samples_different_values` | 有序采样时间、标签、各来源时间一致，但输入值不同 | 相同样本成员上的输入方案比较，需检查特征/数值差异 |
| `different_or_unconfirmed_inputs` | 样本、数据、特征顺序或划分有差异，或不能证实一致 | 可比较实验结果，但不能声称控制了输入条件 |
| `insufficient_evidence` | 缺少完整输入摘要 | 不得声称输入相同 |
| `unverified_archives` | 本地归档完整性校验不通过 | 拒绝可信比较 |
| `different_task_types` | 一个训练任务、一个评估任务 | 不应直接比较两者指标 |

接口另外给出“复现实验条件”差异：算法名称、算法参数、运行环境、实现摘要与随机性记录分别标记为一致、不同或证据不足。**这些差异不自动否定不同算法在相同数据上比较的价值**，但需要在结论中明确。

比较基于前后两阶段的 SHA-256：`raw`（时间筛选、对齐、划分之后）及 `model`（输入归一化之后）；二者均分别检查训练和测试数据。新版额外存储采样成员摘要（时间、标签、来源时间戳），用于区分“相同样本不同输入值”。计算摘要**不依赖 4 MiB 输入快照是否完整保存**，但摘要一致不能恢复大数据的完整矩阵。

**注意：** `same_raw_inputs_different_preprocessing` 并不说明哪个预处理更优；它只表明实验条件不同。若不同实验采用不同目标域、实验窗口、标签协议或不同算法阈值，比较应结合实验配置和数据标签语义解释，不应仅按 Accuracy 排名。

## 随机种子

本次将 **MLP（NumPy 自编码器）** 的 `random_state` 参数实际接入局部 NumPy 随机数生成器。默认 42，可在算法参数中更改；**IsolationForest** 原本已支持 `random_state`。随机种子由对应**检测器自身**管理，AAS 不会通过 `numpy.random.seed`、`random.seed` 或 `torch.manual_seed` 全局重置运行进程，避免在线服务多个并发任务相互影响。

新历史归档 `provenance.randomness` 会声明算法随机性控制范围。统计检测器、外部插件及 PyTorch LSTM 等未显式支持平台可验证种子协议的算法，其状态标记为 `algorithm_defined`；不能声称随机过程受 AAS 统一控制。即使 MLP/IsolationForest 种子一致，底层库/硬件、数值线程和训练内部状态仍可能引起差异。

## 复现实验的边界

- 两次实验使用相同输入矩阵 **不等于** 得到相同预测或相同指标；算法超参、模型初始化、随机性和环境都可能不同。
- 历史任务的“输入一致性”是观察到的有效输入摘要，不是另一次训练可从零完全重跑的充分条件。
- 比较接口验证本机受管文件的一致性，SHA-256 不提供外部身份认证或不可抵赖性。
- 旧归档缺少摘要时报告证据不足，不根据数据表名、模型名称或指标猜测。
- 不更改训练/测试划分规则和算法的报警阈值；平台仅核验和记录客观条件。

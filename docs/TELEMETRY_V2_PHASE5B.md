# AAS V2 单一参量数据模型 — Phase 5B

## 用户业务入口（只保留 V2）

浏览：筛选数据用途、数据集命名空间、卫星实例、型号、分系统、部件、参量、时间窗 → 多选逻辑参量 → 时间曲线。不同单位独立绘制；不为浏览曲线强制对齐采样时间。

导入：CSV 的 `timestamp,value,label` 以 V2 原生分片形式事务写入 `datasets/aas_telemetry_v2.sqlite`。必须提供参量身份、数据用途、时间域、数字时基与单位；数据表不是用户输入字段。原始/训练/测试/仿真/处理/故障用途不互相冒充。

训练：工作台「算法运行」选择 1–8 个已确认训练用途的逻辑参量、时间范围、对齐方式（exact、nearest、previous）、最大偏差、算法和归一化方法；每个参量先跨同一时基同一用途分片拼接，再对齐到首参量时间轴；只接受正常标注 `label=0`；按时间顺序进行内部训练/验证划分。模型保存真实参量身份、来源分片与指纹、时基、特征顺序、训练期归一化参数。

评估：从已发布 V2 模型恢复契约，自动匹配已确认测试用途的逻辑参量；不允许因选择顺序改变训练期特征顺序。最终对齐后的测试数据必须同时包含正常、故障真实标签。加载发布模型进行评分，不重新训练，不使用测试数据拟合归一化。源身份和时基不符则拒绝。事件级指标依赖已有实际可观测数据及标签语义，告警后处理仍由具体检测算法负责。

## 停用旧业务路径

以下不再是对用户开放的可选数据模式：物理表浏览/导入/删除、多表选择器、旧表训练、旧表评估、旧模拟数据库。旧训练/评估和数据库管理接口返回 HTTP 410；工作台不再展示旧模式或「模拟数据库」模块，旧 `/simulation.html` 地址重定向到 V2 数据浏览。旧式网页仿真故障注入、旧配置实验执行及旧数据库备份/恢复网页功能**当前暂时停用**，并未移植为 V2 原生仿真任务。

目前请停止服务后使用文件副本或 SQLite 备份命令保护 V2 库；下一阶段应实现只针对 V2 的在线安全备份功能。旧报表与插件内部仍可能包含只读历史格式字段；这些不是第二套用户选择配置。旧模型不在 V2 评估列表中，必须使用 V2 数据重新训练。针对旧物理表的事件编辑、预处理、配置实验及 CLI 旧入口尚未完成 V2 改造，本轮不宣称它们可用于 V2 生产工作流。

## 退役历史 SQLite 文件（先核验，再移出活动目录）

停止 AAS 服务，核实 V2 已安装在 `AAS/datasets/aas_telemetry_v2.sqlite`，且重要记录已成功迁入（包括不能标准化的保留记录）。请先备份整个项目目录。

```bash
cd AAS
python scripts/retire_legacy_databases.py
python scripts/retire_legacy_databases.py --apply
```

第一条仅审计，不删除。第二条确认 SQLite 完整性、外键、版本、迁移来源登记和不存在未处理的事务日志后，备份并逐文件 SHA-256 验证 `history_sample.db`、`simulation.db`、`history_manifest.db`、`historydb.db`，再从**当前安装的** `datasets/` 移除。备份保存在 `AAS/backups/legacy-retired-*/`，如需彻底物理清除备份须由管理员在完成迁移核对后独立决定；本工具不会不可恢复地丢弃旧记录。

只有数据库来源登记不代表每条历史记录已变成标准训练样本。V2 迁移样例的 `v2_legacy_rows` 仍保存 10,711 条待治理历史记录。用途仅凭表名推测、无明确数字时基、时间戳冲突的旧记录不能被自动纳入 V2 训练。不要靠猜测数据用途或者挑选冲突的一条样本来绕过校验。

## 当前边界与测试

- V2 训练/评估单通道最多 200,000 条采样，多通道对齐最多 200,000 个时间点；1–8 个参量。超过时拒绝而不截断。
- 跨多个时基、训练/测试用途混用、同参量同时间不同数值或标签、过期训练指纹被拒绝。
- 无时区的历史时间戳不自动提升为 UTC。`nearest` 可以使用未来观测，仅适合离线处理；`previous` 不读取未来观测。
- V2 原生 **写入/导入、浏览、训练、发布、评估** 路径已实现；V2 原生事件编辑、预处理与仿真故障注入仍需后续迭代。
- 已使用隔离的规范化 V2 测试数据验证完整算法闭环，并对旧库样例副本验证退役。尚未完成目标机器浏览器全流程人工验收或旧全量测试（原先的旧表成功路径测试按设计不再成立）。

## API

- `GET /api/v2/telemetry/series/search?role=train|test|raw|...` — 筛选逻辑参量
- `POST /api/v2/telemetry/query` — 查询曲线（不自动训练式时间对齐）
- `POST /api/v2/telemetry/import-csv` — CSV 预校验/提交
- `POST /api/v2/training/start` — 按 `channel_ids` 训练
- `GET /api/train-status?task_id=...` — 跟踪训练
- `GET /api/v2/models` — 已发布的 V2 模型
- `POST /api/v2/evaluation/run` — 评分（`model_id`, `channel_ids`, 时间窗）

### 安装提示

代码包只包含程序，不包含任何用户数据库、备份、模型、密钥或运行报告。覆盖原项目后，检查 V2 数据库仍在预期路径，建议先停止服务并备份。已安装 Phase 1–5A 的用户无需重新导入已有数据。**安装代码包不会自动删除你的旧 DB**；需要管理员执行上述审计/退役命令。

# AAS Phase 4：V2 数据访问层与逻辑参量浏览页面

状态：**数据浏览第一阶段可安装候选版（读 V2，不写 V2）**。实施于 2026-10-20。原始工程 `20261020_4.zip` + Phase 1–3 改动 + V2 重建工具为基线。

## 使用流程

打开「数据浏览」后，默认展示：

- **左上筛选条件**：数据用途、来源命名空间、卫星实例、型号、分系统、部件、关键词、起止时间、是否仅显示在时间窗口内实际有样本的参量。
- **左下逻辑参量清单**：逐个勾选（最多 8 项），包含型号、分系统、部件、参量、来源命名空间、时间域、来源分片和样本数，不是 SQLite 表名列表。
- **右上曲线**：多参量各自按照真实采样时间绘制；不同单位分轨绘制，出现明显时间断档则断线。鼠标悬停可以查看时间戳、值、标签、原始表和行号；鼠标左右拖动可以将框选结果填入筛选时段，需再次点击绘制。
- **右下已选曲线**：独立隐藏、显示、移除和 CSV 导出。导出只包含当前实际加载的点，绝不声称是完整数据库导出。

旧版物理表管理、导入、删除、清洗和区间标注保留在「高级：旧版物理数据表管理与兼容操作」，操作旧库**不会同步修改 V2**。

## API 契约

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v2/telemetry/filter-options?role=unspecified` | 获取给定用途的筛选维度 |
| GET | `/api/v2/telemetry/series/search?role=unspecified&model=GF1&start=...&end=...` | 返回逻辑参量，不返回待用户选择的物理表；筛选时间段有实际采样的参量 |
| POST | `/api/v2/telemetry/query` | `{ "role": "train", "channel_ids": [1,2], "start": "...", "end": "...", "limit": 3000 }`，返回每个参量独立时序和来源 |

用户不可在接口中自选任意 SQLite 文件路径。服务端只读打开 `ROOT/datasets/aas_telemetry_v2.sqlite`，强制校验 V2 版本、用途、参量 ID、查询数量和时间域。`role` 仅允许 `unspecified/train/test/simulation/processed/simulated_fault`，不可使用 `all` 混合用途。

### 数据安全边界

- 数据身份包括 `(namespace, satellite_instance, model, subsystem, device, variable)`，即使参量名相同，不同原数据库命名空间不会被自动合并。
- 原始/训练/测试/仿真/清洁用途的分片**不互相混合**。`train/test` 仅允许使用旧库 `aas_table_meta` 明确声明的角色；仅凭表名猜测的角色不放宽为可信训练数据。
- 遗留 `unspecified` 分片若具有冲突的训练、测试、清洁名称提示（例如同时含 `DEMO_train_*`、`DEMO_test_*`），自动查询拒绝拼接，必须先修订数据用途再进入逻辑序列。目录会标识该状态。
- 不同时基 (`numeric_unspecified`、`datetime_naive`、`datetime_utc`) 不能拼到同一条曲线或在同一绘图区比较。无时区字符串在坐标计算时仅作为本地墙上时间排序，不认为已经拥有 UTC 语义。
- 同一参量、同一用途、同一时间戳的完全重复点去重计数，不一致的数据值或标签立刻拒绝绘制，而不是自动覆盖。
- 对齐只用于训练/评估数据矩阵；本页各参量保持独立采样，不插值、不填充，不伪造故障报警协议。
- 单个参量每次最多返回 5000 条**物理**记录，页面默认 3000；超出显示 `truncated`。请缩小时间范围，CSV 只包含加载的样本。
- V2 数据库没有写入端点。旧版导入/删除不会操作这个文件；迁移需要停止服务并显式重建，不能原地替换历史业务数据库。
- 老表中的不可映射宽表与历史管理记录保留在 `v2_legacy_rows`，当前不能当作有效逻辑遥测曲线，仍需人工映射。

## 安装

1. 停止 AAS 服务，备份整个项目和 `AAS/datasets` 下的数据库。
2. 如果还没有原版工程，先解压 `20261020_4.zip`；将 Phase 4 累积补丁 ZIP 解压到 **AAS 的父目录**，覆盖 `AAS/...` 同名代码文件，不删除原目录。
3. 另行解压已经交付的 `AAS_telemetry_v2_database_20261020.zip`，从中找到 `AAS_telemetry_v2_rebuilt_20261020.sqlite`，**复制**为 `AAS/datasets/aas_telemetry_v2.sqlite`（请确认目标不存在，避免覆盖自己的新库）。该重建库来自历史样例，不等同于生产数据。
4. `python -m pytest -q tests/test_telemetry_v2_browser_phase4.py tests/test_telemetry_v2_rebuild.py tests/test_data_api_route_extraction.py`
5. 通过原服务 `python scripts/visualization_server.py --host 127.0.0.1 --port 8765` 启动，登录后访问「数据浏览」。
6. 在未指定用途下检查逻辑参量清单，切换训练/测试再查询；若提示用途不明、时间基准冲突，应先完成数据治理，而不是强制合并。

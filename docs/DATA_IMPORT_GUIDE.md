# 数据用途识别与智能批量导入

## 1. 数据用途

数据浏览中的业务表会显示以下用途之一：

- `训练集`：标签可识别且全部为正常样本（`label=0`）。
- `测试集`：同时包含正常样本（`label=0`）和故障样本（`label=1`）。
- `未指定`：缺少足够信息，或用户明确选择“不指定”。

导入时可选择“自动识别”“训练集”“测试集”“未指定”。如果显式指定训练集或测试集，后端会再次校验数据组成；不满足时拒绝导入。

自动识别得到的用途会标记为“自动识别”，用户显式指定的用途会标记为“已声明”。

## 2. 导入方式：单表导入 / 批量导入

导入弹窗提供两种明确分开的工作模式：

- `单表导入`：一次选择 1 个 CSV/JSON 文件，最终只生成 1 张数据表。系统会先自动识别字段，用户可以继续手工调整“时间戳、型号、分系统、单机、参量、值、标签”的映射及表名。适合结构特殊、列名不规范或需要人工确认的数据。
- `批量导入`：可一次选择多个文件，也支持一个宽表自动拆成多个参量表。该模式**只使用自动识别结果**，不再显示单表字段映射表单，避免一个“参量/值”映射误导整批数据。

批量模式会在导入前自动做规范检查：

- 时间戳、型号、分系统、单机、参量和值等必填映射是否完整；
- 训练集是否满足“仅正常数据”；
- 测试集是否同时包含正常和故障数据；
- 宽表遥测列是否能解析成有效的“分系统.单机.参量”；
- 缺少型号时是否已经填写“默认型号”。

只要存在阻断问题，文件会在批量计划中标红，并提示具体缺失项；“开始批量导入”会拒绝执行。此时可：

1. 修改 `configs/data_import_aliases.yaml` 增加列名识别规则；
2. 补充“默认型号”；
3. 或切换到“单表导入”后手工完成字段映射。

## 2.1. 可选的缺失值填充

在 **数据浏览 → 导入数据 → 3. 配置导入选项** 中勾选「缺失值填充」，即可在入库前对测量值应用前向填充（单表/批量均支持）；**默认不勾选**，原始数据按原逻辑导入。

- 填充字段仅为映射后的数值测量字段 `value`，空字符串、全空格、`NA`、`N/A`、`NaN`、`null`、`none`（不区分大小写）被视为缺失。
- 按**源文件的原始行顺序**处理，仅复用相同 `model + subsystem + device + variable` 序列之前的有效数值；不跨参量、型号或设备填充，也不读取未来行，不对序列起始位置作猜测。
- 序列起始缺失数据保存为 SQLite `NULL`；没有完整分组标识的数据不会用其他序列填充。
- **不填充**时间、型号/分系统/单机/参量标识、标签 `label`（真值）等字段。导入之后返回已填充个数和未能填充个数。被填充的测量值参与后续算法训练与评估，建议根据实际数据质量决定是否开启。

例如 `soc` 的源测量值按文件顺序为 `0.9, 空, 0.7, 空`，开启后写入 `0.9, 0.9, 0.7, 0.7`。若第一条为空，则第一条仍为空，不使用后续值填充。

## 2.2. 删除历史数据表

进入 **数据浏览**，在页面顶部点击与「导入数据」并列的「删除数据表」，在独立的数据表管理弹窗中浏览或搜索当前历史数据库的业务表；点击某项「删除」，在二次确认弹窗中**手动输入完整表名**才能执行永久删除。

删除会在一个事务中清除当前业务数据表、同名的 `_clean` 清洁表（如果存在）以及相关 `aas_table_meta` 导入元信息；**不会删除整个数据库或其他业务数据表**。删除后重新读取数据库目录、级联筛选和图表。后端拒绝删除 SQLite 系统表、AAS 内部元数据表、隐藏清洁表及非历史数据浏览业务表；数据库路径限定在受管理的 `datasets/` 目录内。

**删除不可撤销。** 建议操作前在「数据备份」页面备份数据库。该功能删除的是 SQLite 表，不会清除之前生成的模型文件和实验报告；如果模型或实验仍引用已删除的数据表，需要重新选择有效的数据源。

## 3. 自动识别列名

导入预览会尝试识别常见中英文列名，例如：

- 时间：`timestamp`、`time`、`time_s`、`时间戳`、`采样时间` 等；
- 标签：`label`、`fault_active`、`label.fault_active`、`故障标签` 等；
- 型号、分系统、单机、参量和值：对应常用中英文名称。

系统不会在文件完全缺失“型号”信息时凭空猜测型号。批量导入时可在“默认型号”中填写一次，供所有缺失型号字段的文件复用。

## 4. 宽表遥测列自动拆分

对 `eps.battery.soc`、`eps.battery.storage_wh` 这类 `分系统.单机.参量` 列，系统可以自动拆分为独立 AAS 数据表。一个源文件只上传、解析一次，然后按勾选的参量批量写入多张表。

例如：

- `eps.battery.soc` -> 分系统 `eps`、单机 `battery`、参量 `soc`
- `eps.battery.storage_wh` -> 分系统 `eps`、单机 `battery`、参量 `storage_wh`

批量计划中可以逐项取消不需要的参量，也可以使用“全选 / 清空”。

## 5. 仿真黑盒测试数据示例

对以下三个文件：

- `训练集_正常数据.csv`
- `测试集_电池开路故障.csv`
- `测试集_电池容量突降故障.csv`

自动识别结果应分别为：

- 训练文件：400 正常 / 0 故障 -> `训练集`
- 开路测试文件：150 正常 / 101 故障 -> `测试集`
- 容量突降测试文件：150 正常 / 101 故障 -> `测试集`

如果填写默认型号 `GFSIM1`，并保留 SOC、储能、实际功率、有效容量四个参量，系统会生成与黑盒测试资源一致的 12 张业务表，例如：

- `GFSIM1_eps_battery_soc_train`
- `GFSIM1_eps_battery_soc_test_open_circuit`
- `GFSIM1_eps_battery_soc_test_capacity_loss`

源 CSV 中如果还包含其他遥测参量，它们也会出现在批量计划里；不需要时直接取消勾选即可。

## 6. 批量导入的事务边界

同一个源文件拆分出的多张表在一个数据库事务中写入：其中任意一张表校验或写入失败，该文件对应的本次写入会整体回滚。多个源文件按顺序逐个处理，避免一次性把大量文件同时加载到内存。

## 7. 自动识别规则配置文件

列名与字符串标签值的自动识别规则已独立到：

```text
configs/data_import_aliases.yaml
```

修改该文件后**无需重启 AAS 服务**；下一次选择文件并执行导入预览/解析时，服务会根据文件修改时间自动重新加载规则。

例如，若现场 CSV 使用以下列名：

```text
satellite_type,sys_name,unit_name,telemetry_name,telemetry_value,fault_flag
```

可在对应字段中追加：

```yaml
columns:
  model:
    - model
    - model_name
    - satellite_model
    - satellite_type
    - 型号
    - 卫星型号

  subsystem:
    - subsystem
    - subsys
    - sys_name
    - 分系统

  device:
    - device
    - component
    - unit_name
    - 单机

  variable:
    - variable
    - parameter
    - telemetry_name
    - 参量

  value:
    - value
    - measurement
    - telemetry_value
    - 数值

  label:
    - label
    - fault_flag
    - 故障标签
```

如果标签值使用 `N/F` 或“正常状态/故障状态”，可修改：

```yaml
labels:
  normal:
    - "0"
    - normal
    - N
    - 正常
    - 正常状态

  fault:
    - "1"
    - fault
    - F
    - 故障
    - 故障状态
```

列名匹配不区分大小写，并会把点号、空格、短横线等统一归一化后再比较。例如 `Fault Active`、`fault-active` 会按 `fault_active` 参与匹配。

如果某一节没有配置，系统会对该节使用内置默认值；如果配置文件不存在，则整套规则使用内置默认值。若 YAML 格式错误、字段类型错误，导入预览会明确报错，而不会静默使用错误配置。

## 6. 多特征宽表单表导入

单表模式允许源文件含多个数值测量列。完成标准字段映射（必须包含 `timestamp`、`model`、`subsystem`、`device`、`variable`、`value` 和按数据用途需要的 `label`）后，未被映射消费且名称仅包含字母、数字、下划线的其他数值特征列会保留在同一 SQLite 表中；例如 `value`、`temperature`、`vibration`、`current`。随后可在数据浏览中多选绘图，在算法运行中选择多列训练。数字缺失值在训练时按“完整行”剔除，不会默默当作 0。

注意：批量导入的带点遥测列依旧拆为多张表，与单表保留多列的模式不同；当前「导入缺失值填充」开关仍针对映射的主测量列 `value` 执行前向填充，并不隐式填充所有其他特征列。

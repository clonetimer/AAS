# history_sample.db 训练/测试样本补充说明

`history_sample.db` 为混合历史数据配置了独立的训练表与留出测试表，不修改原始历史表的数据内容。

- `*_train`：仅包含原表中的正常样本（`label=0`），取正常样本的 80%，用于模型训练。
- `*_test_holdout`：包含剩余 20% 正常样本与原表全部故障样本（`label=1`），与对应 `*_train` 不重叠，用于本地评估。
- 原有混合历史表保持不变，仍可用于历史数据浏览。
- 原本全正常的 `GF1_subsys1_solar_panel_voltage` 和 `GF_attitude_error` 直接声明为训练集，不重复复制。
- 训练/测试角色写入 `aas_table_meta`，AAS 界面会据此显示 `[训练集]` / `[测试集]`。

训练表与留出测试表由已有数据划分形成，没有为这些表人工增加遥测测量值。若需要扩充**独立的新正常样本**，应另行生成或采集，并通过数据导入功能加入。

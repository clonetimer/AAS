# 模型管理与输入契约

## 模型生命周期

训练完成后，模型工件保存在 `models/model_<实验ID>/`；常见文件包括 `config.json`、`metrics.json` 和算法参数文件。模型发布信息单独记录在 `models/model.db`，并由算法运行页面管理。

已保存模型与已发布模型是不同状态。发布操作不会重新拟合算法；评估已发布模型时读取相应工件和配置。

## 输入数据契约

训练配置记录输入特征列名及顺序、每列归一化参数、清洁/原始数据视图以及相关时间选择。评估必须提供相同特征及顺序，并使用训练保存的变换参数，不在测试集上重新拟合。输入特征缺失或数据视图冲突时会报错。

评估应使用有效的真实标签：`label=0` 为正常，`label=1` 为故障。模型本身输出的预测不应被用作真实标签。

## 模型记录与关联

模型和评估报告通过模型标识与实验标识关联。删除历史数据库表不会自动删除已有模型和报告；再次评估时仍须选择可访问的数据集。

## G0-3 through G0-6 — Candidate v3 (2026-11-07)

### G0-3: Unified CSV import guidance

- Added a shared five-stage presentation component for history, simulation, training and test CSV imports: select file, check format, verify purpose/mapping, preview/confirm, write/result.
- Existing business APIs, label/role isolation, SHA-256 input checks, preflight confirmation and database transactions remain unchanged.
- UI state is driven by the existing import controllers; an error does not automatically replay an import.

### G0-4: Contextual fault parameter help

- Built-in bias, drift, fixed-target and periodic-spike faults display distinct parameter meanings, units and validation hints.
- CSV fixed-target allows zero, but other three CSV fault magnitudes require nonzero finite values. The historical simulator retains its own stricter zero rule and time-based drift formula.
- Switching CSV fault types preserves each type's own draft magnitude; no change to fault mathematics.

### G0-5: Safe, bounded page drafts

- Versioned, allowlisted localStorage drafts for selected static runner/browser filters and parameters; 4 KiB bound and input validation.
- Explicit clear button; restore never treats old previews as valid, nor stores CSV bytes, telemetry arrays, model objects, secrets or execution receipts.
- Model selection, dynamic channel bindings and complex cross-page context are **not** yet restored. Real browser usability acceptance remains pending.

### G0-6: Consistent task-history scope

- Home and task centre share the same summary projection of the latest 100 task records while separately displaying the server-reported durable total.
- Running includes cancelling; report-attention is a completed-task subset and is not double-counted as failed.
- History service failure is shown as unavailable rather than a fabricated count of zero.

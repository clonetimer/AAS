## 范围及界限

1. 扩展已有二进制来源导入服务：只读识别 UTF-8（含 BOM）、GB18030 和逗号/分号/TAB 格式；返回可审核的识别结果。
2. 训练/评估页面显示编码和分隔符控件，用户检查列后再预检、确认导入。所选格式在预检与提交间必须保持一致。
3. 预检及提交共用解析器，转换为现有宽表导入规范，来源 SHA256 仍取原始上传字节；标签、时间、数据身份与分组保护不变。
4. 只完成易用性增量：暂不开展无限大小上传、后台任务和未经认证的模型迁移；旧导入客户端不传新字段时继续保持 UTF-8 逗号格式语义。

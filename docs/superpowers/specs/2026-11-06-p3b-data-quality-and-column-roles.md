# P3-B：数据质量摘要与列角色管理设计

日期：2026-11-06  
前置：P3-A 统一 CSV 格式检查已完成。  
状态：按用户继续推进授权实施；只修改数据导入/预览层，不改变算法内核和既有标签规则。

## 目标

从实际用户角度，解决“文件导入成功但数据问题要等到训练时才发现”“不知道哪一行/哪一列有问题”“时间列、标签列和参量列只能依赖固定列名”“每次导入都要重新做同一套映射”等问题。

## 本阶段范围

1. **统一质量分析**：增加共享 `csv_quality.py`，在历史库 CSV/CSV.GZ 检查和模拟 CSV 检查时统计缺失值、非数值/非有限值、重复时间、时间倒退、采样间隔异常、标签值分布及结构错误。
2. **行级定位**：最多展示前 20 条问题，字段包括数据行号、帧号、列名、问题类型、原始值摘要和建议；同时显示总问题数与是否截断。质量检查不静默修复原始数据。
3. **明确列角色**：历史数据库导入允许用户明确选择时间列、标签列（可选“无标签”）、要导入的参量列和忽略列；不再仅依赖 `time_s`/`timestamp`/`label`/`fault_label` 固定名称。
4. **映射编辑可靠性**：当前映射表输入项需要绑定到实际状态；编辑后的单位/分系统/部件/参量必须进入预检与写库，不能只改了界面文本。
5. **本机映射预设**：可将时间列、标签列、包含参量和属性映射保存到当前浏览器配置；仅对列集合匹配的文件提供应用选项。预设只存映射元数据，不存 CSV 内容；提供删除预设。
6. **不破坏科学性门禁**：未知标签仍为未知；选择无标签后，训练/测试用途确认规则继续生效；时间戳重复/倒退可以预览，但是否允许建模仍由严格预检决定；不自动填充、不自动把非数值变成 0。

## 用户流程

`选择文件 → 格式确认（P3-A）→ 质量摘要 → 选择时间/标签角色 → 勾选参量/忽略列 → 属性映射 → 预检 → 确认导入`

- 普通浏览/检查只读，不写数据库。
- 质量面板先显示总体摘要，再显示前 20 条具体问题；用户可以定位到原始行。
- 质量提示不等于全部错误都可忽略；预检/提交仍执行现有全量约束。
- 选择“无标签”时，明确显示原文件中的标签列是否被忽略；不生成监督指标。
- 本机映射预设仅在列名集合匹配时启用；映射文件 CSV 仍保留为可跨机器交换的方式。

## 质量指标定义

- 缺失：空字符串或空值。
- 非数值：非空值无法解析为数字。
- 非有限值：`NaN`、`Inf`、`-Inf` 等虽可转换但非有限的值。
- 重复时间：时间值与此前任一时间值相同，按重复出现次数计。
- 时间倒退：当前有效时间小于上一有效时间。
- 采样间隔异常：正间隔大于该文件正间隔中位数的 3 倍；仅提示，不作为自动拒绝的唯一依据。
- 标签：只有明确选择的标签列且值符合 0/1 时才作为二值真值；其他值列为未知/无效，不擅自二值化。
- 行号：CSV 表头为第 1 行，第一条数据为第 2 行；帧号从 1 开始。两者同时显示，避免混淆。

## 技术约定

- `analyze_csv_rows(header, rows, *, time_column=None, label_column=None, max_issues=20)` 返回质量摘要、角色建议、数值参量建议和有界问题列表。
- `telemetry_v2_source_import.source_operation(inspect)` 返回 `quality`、`time_candidates`、`label_candidates`、`numeric_columns`。
- `v2_csv_workspace.inspect_csv` 返回同一质量结构；模拟库持久化质量摘要及格式来源元数据，派生版本继承质量结构（故障注入只改有限数值，不改帧结构/标签/时间轴）。
- 历史导入配置支持 `time_column`、`label_column`（空字符串表示无标签）和 `selected_columns`；`telemetry_v2_wide_import._prepare` 使用明确列角色。
- 映射输入编辑后必须更新内存映射对象，预检/提交从同一状态构造 payload。
- 本机预设使用 `localStorage`，key 带 schema 版本；只存映射，不存文件数据或敏感值。

## 验收标准

1. 对含缺失、无效数字、NaN/Inf、重复时间、时间倒退、间隔异常、未知标签的 CSV，质量摘要计数与独立手算一致。
2. 行级问题显示准确的 1-based CSV 行号、帧号、列名和原值摘要，问题列表最多 20 条且显示总数。
3. 非标准时间列名（如 `采样时刻`）可以指定为时间列；非标准标签列名（如 `fault_state`）可以指定为标签列；也可显式选择无标签。
4. 被忽略的文本/无效列不进入测量矩阵；被选择的列属性编辑真实进入预检和写库。
5. 保存预设后刷新页面仍可用；列集合不匹配时拒绝静默套用；删除预设后不再显示。
6. 未知标签不变成正常；无标签训练/测试确认、运行组隔离、时间一致性、模型特征契约和原始数据不可变约束保持。
7. 模拟/历史导入页面的质量摘要和角色选择均有浏览器交互测试；后端有质量计算、列角色与旧库迁移测试。

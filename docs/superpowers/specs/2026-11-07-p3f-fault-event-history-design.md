# P3-F：故障事件时间线、撤销与版本差异设计

## 意图

让 AAS V2 的本地 CSV 故障模拟从“连续生成不可变版本”升级为可审计的事件工作区。用户需要看清多个故障事件的注入顺序、同参量重叠区间、单事件撤销后的数据变化，以及任意祖先版本回退前后的差异。

## 目标

- 将故障事件明确标记为 `active` 或 `retracted`；兼容没有状态字段的旧事件，默认视为生效。
- 按事件保存顺序重建故障结果；同参量事件按 1-based 闭区间计算重叠，跨参量不视为重叠。
- 单事件撤销必须先预览，再提交新快照；从原始 CSV 重放所有仍生效的事件，旧版本不修改。
- 版本回退只允许回退到当前版本的严格祖先；回退结果作为当前版本的新子版本保存，旧快照不删除。
- 版本比较逐帧统计所有列的变化帧和变化单元格；曲线点数与变化区间列表有上限，不能影响完整统计。
- 列表只返回事件/操作计数，事件明细按选中版本读取，避免每个版本都携带完整账本。
- 事件撤销、版本回退、事件状态变更和结果摘要写入操作审计记录。

## 非目标

- 不修改历史遥测主数据库、训练标签、模型或数据集治理规则。
- 不覆盖、删除或重写已有 CSV 版本。
- 不将不同参量按时间或行号强行对齐。
- 不增加 Redis、Celery、后台服务或第三方运行依赖。
- 不改变现有 CSV 导入、故障注入参数定义和完整 CSV 导出格式。

## 方案比较

### 方案 A（采用）：不可变快照 + 事件账本状态 + 从原始数据重放

为版本表增加 `operations_json` 审计列；旧事件通过默认值迁移。撤销时从原始 CSV 依事件顺序重放剩余生效事件；回退时复制祖先内容到当前版本的新子版本，并将后代事件标为撤销。优点是保留现有 SQLite 快照模型、兼容旧库、无需后台任务；代价是撤销需要重放事件。

### 方案 B：保存每个事件的反向补丁

可以局部撤销，但多个重叠故障的非交换运算（如 bias、drift、stuck）使反向补丁依赖后续事件顺序；维护和审计更复杂，容易出现错误回滚，因此不采用。

### 方案 C：数据库原地更新与事件删除

实现简单，但破坏不可变版本与审计链，且无法可靠回退，不符合现有工作区约束，因此不采用。

## 数据与操作约束

- `events_json` 中每个事件包含唯一 `event_id`、正整数 `sequence`、`status`、非负 `revision` 及原有故障参数。
- 旧事件缺失 `status/sequence/revision` 时按列表顺序规范化为 `active/index+1/0`；未知状态、重复顺序或非法 ID 一律拒绝。
- `operations_json` 记录 `event_retracted`、`version_rollback` 操作、来源版本、目标事件/祖先、时间和结果内容摘要。
- 事件重叠采用闭区间：`max(start_a,start_b) <= min(end_a,end_b)`；只有同一参量之间才计算重叠。每个事件返回精确重叠总数，但最多携带 20 个重叠示例，避免高重叠场景造成 O(n²) 响应体膨胀。
- 撤销预览摘要绑定源版本内容摘要、操作目标、重建结果摘要和事件状态；提交时必须重新计算并匹配。
- 回退目标必须在当前版本的父链上，兄弟版本和其他导入根均拒绝。
- 比较版本必须属于同一原始 CSV 导入链，字段和帧数一致；全量扫描统计，曲线最多 2,000 点、变化区间最多 1,000 段。
- CSV 导出和曲线故障覆盖只反映 `active` 事件；`retracted` 事件保留在审计时间线中。

## API 与界面

- `GET /api/v2/csv-workspace/events?id=...`：返回事件时间线、同参量重叠和操作记录。
- `GET /api/v2/csv-workspace/ancestors?id=...`：返回严格祖先版本链。
- `GET /api/v2/csv-workspace/compare?before_id=...&after_id=...&column=...`：返回逐帧统计、变化区间、事件增删和有界曲线点。
- `POST /api/v2/csv-workspace/event-retract-preview` / `event-retract`：单事件撤销预览与确认提交。
- `POST /api/v2/csv-workspace/rollback-preview` / `rollback`：祖先版本回退预览与确认提交。
- UI 在选中版本下显示事件时间线、状态和重叠区间；撤销和回退必须经过确认；祖先选择器支持比较曲线和回退。

## 验收

- 旧事件默认生效；状态损坏时拒绝读取。
- 同参量闭区间重叠解释准确，其他参量不误报。
- 单事件撤销重放剩余事件，旧快照逐字节逻辑内容不变。
- 预览摘要不匹配时不创建新版本。
- 兄弟版本不可回退；祖先回退创建新子版本并更新事件状态。
- 版本比较全帧计数准确、输出点数有界、缺帧时 fail closed。
- 撤销事件不再出现在曲线故障覆盖和机器 CSV 的生效故障标记中。
- 50,000 帧测试覆盖比较、撤销和回退。
- HTTP 鉴权路由和浏览器交互契约通过。
- Windows 10/11 验收仍在 P3-H，不由本阶段 Linux 测试代替。

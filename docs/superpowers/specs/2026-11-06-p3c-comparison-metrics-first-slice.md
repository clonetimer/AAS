# P3-C 第一批：监督评估实验并排指标对照

2026-11-06。目标：保持原有 `/api/compare-experiments` 的归档验证与输入可比性判定，在严格条件满足时为非程序员显示两次实验的相同指标及差值。仅增强后端只读返回字段和报告页，不改变模型或指标算法。

## 允许展示的条件

两份归档均已通过摘要验证，已归档结果中的输入证据与摘要一致，实验均是 `evaluation`，`evaluation_mode=supervised`，`ground_truth_available=true`，并且分类是 `identical_model_inputs`。只对两边都有且均为有限数值的白名单监督指标提供行：准确率、精确率、召回率、F1、ROC AUC、误报警率及已支持的事件指标。值直接来自经过验证的归档结果；不得凭模型注册表填充，也不重新计算。

训练/评估类型不相同、score-only、没有真实标签、原始或模型输入不相同、指标缺失时均不得展示可比较的数字；显示原因。数值差值恒为右－左，不通过颜色、图标或自动排序暗示“更好”，尤其误报警率和延迟的增大不是性能提升。指标名和数值均通过 DOM `textContent` 填充。

## 本次验收

- `tests/test_experiment_comparison.py`：同输入监督评估只返回白名单指标；不同输入或无真值不生成比较表；原有归档校验、HTTP 认证和路径限制仍通过。
- `tests/report_comparison_metrics_ui.cjs`：真实报告页比较事件在可比时生成并排表，在不可比时隐藏；不出现无真值排名。
- `LOCAL_TEST/Run-UpgradeTests.ps1`：增补上述测试和 P3-B 相关专项，现有 Windows 实机验收结论不随此变化。

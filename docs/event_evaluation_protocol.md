# 事件级评价与标签语义

AAS **仅统计具体检测器已输出的逐点 `pred_labels`**，不重新决定阈值、不做连续 N 点报警、平滑、滞回或报警抑制。这些均属于检测器自身的策略。

## 事件级召回

故障事件采用 `[start, end)` 时间区间。仅当事件起点及完整事件区间位于可观测评价窗口中，且区间内有有效采样点时，事件才计入 `fault_events_evaluable`。首次报警延迟使用事件开始时间到该事件区间内第一次由检测器输出的异常判决（`pred_labels == 1`）的时间差。起点位于观测窗口之前的左截断事件、结束时间超出观测窗口的右截断事件或区间内没有样本的事件，都不计入召回率分母。指标会分别报告不适用事件数和右截断事件数。

## 联合正常时段误报率

对于单参量，只有明确标记为“已确认正常”的时间点，才能进入正常误报率的分母。对于多个输入参量的联合评估，某个时间点只有满足以下条件才算**联合已确认正常**：

1. **每个**当前评估输入参量在该时间点均有有效的正常区间标注；
2. 没有任何输入参量在该时间点存在故障事件标注。

任何一个参量未标注都视为“未知”，不能被平台默认为正常；任何一个参量有故障都标记为联合故障，不能被误算为正常误报。即使多个参量在同一时间点均标注正常，联合正常样本也只计数一次。`confirmed_normal_false_alarm_rate` 为联合正常样本中检测器输出异常判决的占比；不存在此类样本时指标为 `null`，而非零。

`joint_fault_samples`、`joint_unknown_samples` 和 `joint_annotation_policy` 用于解释指标分母。多参量来源的故障事件则仍按**来源事件**分别计算事件级召回，以保留各参量的事件追溯语义。

## 结果归档

报表曲线使用真实异常分数和检测器返回的阈值，不构造代用阈值。历史记录的二值预测必须是 0/1（含其字符串表示），不能将字符串 `"0"` 按布尔值转换成异常。非法或缺失预测时，曲线仍可展示分数，但预测标签不可用，事件级指标显示不可计算。事件指标从完整预测序列计算，卡片中抽样后的曲线仅用于展示。

## 使用边界

此机制是离线结果的客观评价，不对检测算法输出进行后处理或重新定阈值。事件标注的准确性、多个来源事件是否指代同一物理故障，以及用户提交的训练/评估任务是否可复现，需由数据和实验管理流程另行保证。当前浏览器向历史保存接口提交结果；接口中的事件标注从受管数据库读取，但算法结果本身并非签名的服务端不可篡改记录。
